# Exercise equipment

Researched 19 October 2026.

## Evidence

- [Hevy: creating, editing and duplicating custom exercises](https://help.hevyapp.com/hc/en-us/articles/34264544382615-How-to-Create-Edit-and-Duplicate-Custom-Exercises-in-Hevy) separates equipment from muscle groups and exercise tracking type. Equipment is editable metadata.
- [Strong: creating custom exercises](https://help.strongapp.io/article/97-create-custom-exercises) supports creating exercises in the library and during a workout.

## Auctus decision

Equipment belongs to the reusable exercise, separately from the set type (normal, warm-up, dropset, failure) and its prescribed reps/rest. Require a deliberate choice in every creation/edit form using the existing custom menu:

- Dumbbells
- Stack machine (pin-selected load)
- Plate-loaded machine
- Cable machine (including rope attachments, as clarified by the user)
- Other (covers exercises outside the four requested groups without misclassifying them)

A cable machine often also has a weight stack. In this menu, choose Cable machine when using a cable/attachment; Stack machine is for other selectorized machines. This is a deliberately practical classification based on the user's training, not an exhaustive equipment taxonomy copied from a competitor.

Display equipment beside the exercise name in the library, search suggestions, template editor, session exercise list/detail and history. Keep the equipment label neutral so blue/orange/red/green still describe workout state.

Snapshot equipment when a session starts or an exercise is added mid-workout. Changing the library later must not rewrite history. Previous-weight suggestions and the active session's “Last time” comparison require matching equipment. Warm-up and working sets keep their own prior weights. Dumbbell weight remains per dumbbell; unilateral repetitions remain per side.

Use separate exercise entries for equipment variants when tracking their progression separately. Existing exercises and historical sessions receive null equipment (shown as “Equipment not set”), avoiding unreliable guesses from their names. No account data needs deletion. Older clients may omit the field without clearing a saved choice.
